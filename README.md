# RN Earnings Timer
A React Native earnings timer with start, pause, resume, and real‑time income tracking. Built with React Native, TypeScript, Notifee, and React Navigation.

## Features
- Start, pause, resume and reset the timer
- Real‑time earnings calculation
- Foreground and background notifications powered by Notifee
